# Vanishree Kulkarni — Official Portfolio

Professional portfolio website for **Vanishree Kulkarni**, acclaimed Indian actress and multilingual voice artist based in Bengaluru, Karnataka.

Featuring her work across live stagecraft (12+ years under Padma Shri M. S. Sathyu), television serials (*Neenade Naa* on Zee Kannada, Star Suvarna), feature films (*Night Out*), short cinema (*Vruksham*), web series (*Ayyana Mane* on Zee5), and 20+ years of multilingual voice artistry & dubbing across Kannada, Telugu, Hindi, Marathi, and English.

---

## ✨ Features & Sections

- **Hero:** Interactive portrait cutout with smooth cursor tracking, verified career highlights, and modal showreel player.
- **About:** Interactive portrait photo-stack showcasing her disciplines across screen acting, live theatre, voice artistry, and character roles.
- **Selected Work:** Production cards covering her major performances across streaming, television, cinema, and theatre.
- **Artistic Journey:** Illustrated chronological roadmap of her career milestones and training.
- **Performance Disciplines & Dubbing Toolbox:** Interactive draggable skill pills spanning character acting, dialects, vocal modulation, and stagecraft.
- **Credentials & Recognition:** Certificate wall and live odometer scoreboard displaying verified career statistics.
- **Contact:** High-resolution optimized contact card with one-click casting email enquiry, clipboard copy, and direct social links.

---

## 🛠 Tech Stack

- **Framework:** React 19 + Vite 8
- **Animation & Motion:** GSAP (ScrollTrigger, Flip, MotionPath) & Lenis smooth scrolling
- **Styling:** Modular modern CSS with responsive design, fluid typography, and peach/coral aesthetic
- **Typography:** Bricolage Grotesque, DM Sans, and Caveat
- **Assets:** High-resolution compressed WebP imagery with responsive fallbacks

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- npm

### Installation

```bash
npm install
```

### Local Development

```bash
npm run dev
```

Visit `http://localhost:5173/` in your browser.

### Production Build

```bash
npm run build
```

The production-ready assets will be generated in the `dist/` directory.

### Preview Production Build

```bash
npm run preview
```
